==============================================================================
  温漂补偿：批量最小二乘 vs 遗忘因子 RLS vs 热模型外推
==============================================================================

  设置：漂移 10%，热时间常数 5.0 s，K_O=200，RLS 遗忘因子 λ=0.999
  关键事实：δ 在自由段末(t=4.0s)只到 0.0551，接触段末(t=7.0s)到 0.0753
            => 单调上升，所以'自由段末值'优于'自由段平均值'

  模式                接触段 RMSE       相对无补偿                     δ̂ 取值
  0（不补偿）             0.03395       0.0%           0.0000 (t=4.0s)
  自由段平均 δ            0.03267       3.7%           0.0132 (t=4.0s)
  RLS 末值（保持）         0.02979      12.3%           0.0693 (t=4.0s)
  热模型外推 δ(t)         0.03147       7.3%           0.0254 (t=4.0s)

  结论（严格按数据）
    1. 无补偿 RMSE = 0.03395（这是误差预算里'温漂 10%'那一行）
       自由段平均 δ            -> 0.03267（改善 3.7%）
       RLS 末值（保持）         -> 0.02979（改善 12.3%）
       热模型外推 δ(t)         -> 0.03147（改善 7.3%）
    2. 最优模式 = rls
    3. ★被否定的做法：接触段门控在线自适应。实测发散（δ̂ 达 0.1385，
       真值 0.0753），RMSE 反而恶化 17.6%。根因有二：步长相对采样周期
       过大；且接触段不存在可用于学习的'无接触窗口'。
       => **漂移必须在自由段学好，接触段不许在线学习。**

    ★ 与齿槽补偿合起来，误差预算里两个主要误差源都有了不需额外
      传感器的补偿手段。但注意两者收益量级不同：
        · 齿槽转矩补偿  改善 15.8%（把该项误差几乎完全消除）
        · 温漂补偿      改善 12.3%（部分消除：保持常数而 δ 仍在上升，故有残余）

    ⚠️ 与预期相反：**热模型外推不如简单地保持 RLS 末值**。
       RLS 轨迹本身有滞后，拟合一阶热模型得到的时间常数与幅值都偏低，
       外推反而更差。=> 先验证估计器的跟踪质量，再谈模型外推。
==============================================================================
