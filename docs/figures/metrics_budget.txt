  误差预算：剩余误差来源定位 + 齿槽转矩两级辨识与补偿

  K_O=200 (时间常数 5.00 ms)  齿槽幅值假设=0.02 N*m  温漂=10%

  效应                         无补偿 RMSE        齿槽补偿后        改善       纯电流基线
  ideal      无附加效应            0.02912      0.02868     1.5%     0.17917
  cogging    齿槽转矩             0.03387      0.02852    15.8%     0.17845
  temp       温漂 10%           0.03541      0.03395     4.1%     0.18001
  both       两者兼有             0.04160      0.03395    18.4%     0.17995

  误差贡献分解（相对无附加效应的增量，平方和开根）
    齿槽转矩贡献        = 0.01731 N*m
    温漂贡献            = 0.02015 N*m
    独立叠加预测        = 0.02656 N*m
    实际两者兼有的增量  = 0.02971 N*m
    （预测与实际接近 => 两个误差源近似独立、可用平方和合成）

  结论
    1. 齿槽转矩与温漂都是**显著**误差源，各自贡献与摩擦模型误差同量级
    2. 齿槽转矩可以只靠自由运动段的残差辨识成位置查找表，无需额外传感器：
       兼有两种效应时 RMSE 从 0.04160 降到 0.03395（改善 18.4%）
    3. 温漂是**与电流成正比**的乘性误差，位置查找表无法消除它
       => 必须用在线参数辨识（d 轴电流注入法辨识 R_s 与磁链）单独处理
    4. 这给真实硬件的实验清单提供了优先级：
       先做温度补偿（收益大、成本低、纯算法），再做齿槽补偿（需要位置索引表）
